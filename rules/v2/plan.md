# 이야기 계획 규칙 (컨퍼런스형)

계획표(outline.json)와 발표 데이터(deck.json)를 쓸 때 따른다. 형식은 `style/SCHEMA.md`.

## 큰 흐름
1. **열기** 1~2장 — `statement` 또는 `number`. 이번 회차를 왜 보는지 궁금하게 만드는 숫자 · 질문 하나.
2. **이어 받기** 2장 — 지난 회차 Recap(`statement` + `words` 3개 또는 `diagram` columns 3칸) → 오늘의 길(`diagram` flow, PART 이름 그대로).
3. **PART 마다**(지표 하나 = PART 하나) 5~8장 — 이 차례:
   `part` 간지 → `number` 지금 숫자 → `diagram` 개념(정의 · 구성) → `chart` 읽는 법(추세 · 계절성 · 기준 차이) → `compare` 또는 `diagram` 연결(다른 지표와 잇는 고리) → (장이 남으면) `chart` 심화 · `table` 발표 일정
4. **묶기** 2~3장 — 한 흐름으로(`diagram` flow · hub) + 헷갈리는 짝(`compare`).
5. **토의** 2~3장 — `question`. 정답이 갈릴 수 있는 질문, 보기 3개.
6. **닫기** 1장 — `end`(다음 회차 예고). [참고] 심화는 마지막 장들의 읽기 겹에.

## 분량
- 질문 카드에서 고름 : 짧게 30장 · 보통 45장(기본) · 길게 60장. 1분에 1장 안팎.
- 한 PART 는 전체의 15~25%. 같은 화면 종류가 4장 넘게 이어지지 않게.

## 장마다
- 장 하나 = 생각 하나. 제목은 결론 한 줄 25자 안(「~는 ~임」 대신 「해마다 4월엔 흑자가 줄어듦」처럼 말하듯).
- 화면 글은 40자 안(차트 라벨 · 숫자 · 출처 빼고). 나머지는 `read`(읽기 겹)와 `note`(발표자 메모)로.
- 모든 장에 `read` — head 는 HCG 식 결론 문장(2줄 80자 안팎, 「~임/~함」), points 2~4개, source.
- 숫자가 나오는 장은 `source` 와 `facts` 연결 필수. 데이터월(숫자가 가리키는 달)을 쓰고, 발표월이 다르면 읽기 겹에 적음.

## 도식 고르기 (HCG 레퍼런스)
- `ecs.py find --layout columns --cols 4` 처럼 찾아 칸 수 · 단계 수가 맞는 골격 id 를 `skeleton` 에 적는다(어디서 왔는지 남김).
- 정해진 배치(columns · flow · cycle · hub · tree · pyramid · matrix · timeline · venn)로 그리는 것이 기본. 정해진 배치로 안 맞는 짜임(예 : 가운데 하나 + 위아래 둘 + 오른쪽 결론)만 `layout: "skeleton"`.
- 도식 칸의 글은 head 6자 안 · body 20자 안.

## 숫자
- 사실표(facts.json)에 있는 값만 쓴다. 없는 숫자는 지어내지 않고 장을 바꾼다(개념 · 질문으로).
- 공개 수치 파일(data/series.json)과 자료가 다르면 공개 수치 파일을 쓰고 읽기 겹에 차이를 적는다.
- 단위는 한 장 한 단위. 억 달러 · 조 원처럼 읽기 쉬운 단위로 바꾸면 source 에 원래 단위를 적는다.

## 화면 짜임 (디자인 문법 판 2)
- 모든 장은 `rules/design_grammar.md` 를 따른다 : 밝은 바탕 · 한 색 + 회색 단계 · 왼쪽 위 결론형 제목(`eyebrow` · `title`+`key` · `sub`) · 장마다 다른 짜임.
- 짜임 17가지(G1~G17) 중 장마다 하나. 같은 짜임은 2장까지만 잇는다(포트폴리오는 카드 → 알약 → 반반처럼 번갈아 씀).
  숫자 : G1 지표 카드 · G2 막대 + 강조 하나 · G10 막대 + 강조 선 · G11 미니 차트 카드 · G12 도넛 짝 · G13 크기 원 / 표 : G14 강조 표 /
  구조 : G3 알약 줄 · G15 전후 카드 · G4 문제 카드 · G5 알약 단계 · G16 우물 흐름 · G6 번호 모듈 · G7 화살 단계 · G17 농도 단계 · G8 가운데 + 둘레 · G9 반반.
- 제목이 결론이다(결론형 한 문장). 결론 띠(`concl`)는 PART 마지막 · 요약 · 핵심 숫자 장에만 — 본문의 20~30%. 모양 `pill`(기본) · `band`(PART 마지막) · `top`(복잡한 장에서 먼저 요지).
- 강조색은 회차마다 `theme.accent` 하나(금리 blue · 물가 coral · 산업 violet · 원자재 amber · 기본 green · 색 없이 mono). 한 장에 강조 역할 3가지까지.
- 가운데 정렬은 정의(term) · 문장(statement) · 질문 · 결론 문장 장만.
