# 문체 · 용어 규칙

## 두 겹
| 겹 | 누가 언제 | 문체 |
|---|---|---|
| 화면 겹 | 발표 중 청중 | 짧은 말. 명사로 끝나도 됨. 40자 안 |
| 읽기 겹 | 발표 뒤 혼자 읽는 멤버 | 보고서체 「~임 / ~함」. 결론 → 근거 → 출처 |
| 발표자 메모 | 발표자 | 말할 차례 · 강조할 곳 · 넘어가는 말 |

## 용어 정제
- `terms/glossary.json` 의 「같은 말 묶음」에서 대표 낱말만 쓴다(예 : 전년동기비 ← YoY · 전년 대비 · 작년 같은 달 대비).
- 영어 약어는 첫 등장에 풀이 : GDP(국내총생산). 화면 겹에서 풀이가 길면 `[[GDP]]` 로 용어 풀이에 넘긴다.
- 개발 · 영어 말을 쓰지 않는다(데이터 → 숫자 · 자료, 인사이트 → 시사점).
- 숫자 쓰기 : 천 단위 쉼표, 소수 한 자리, 단위 붙임(3,406.6억 달러). 비율은 %, 차이는 %p.

## 구조화 · 도식화
- 결론부터. 장 제목 = 결론. 근거는 읽기 겹.
- 흐름 · 단계 · 구성 · 비교 · 전후는 반드시 도식 · 차트로(글 나열 금지).
- 강조는 장당 한 곳 : `**초록**`(핵심) 또는 `^^산호^^`(주의 · 이상한 값).

## 하지 말 것
- 투자 권유처럼 읽히는 말(「사야 함」 「오를 것」).
- 블로그 · 기사 문장 그대로 3문장 넘게 옮기기(요약 + 출처).
- 출처 없는 숫자 · 지어낸 예시 숫자.
