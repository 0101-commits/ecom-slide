# 목업 고르기 — 글 짜임 → 계열 (목업 4판)

목업 264종 = 3판에서 남긴 80종(C · M 번호) + 새 목업 184종(N 번호, 19계열). 색인 `library/mockups/index.md`.
장 하나를 계획할 때 **그 장이 말하는 방식(짜임)** 을 먼저 정하고, 아래 표의 계열에서 목업을 고른다. 같은 회차 안에서는 같은 계열을 3장 넘게 잇지 않는다.

```
ecs.py mockup --family F05          # 계열로 후보 보기(kind 이름도 됨)
ecs.py mockup --q 지도               # 낱말로 찾기(주제 · 모양 이름)
ecs.py mockup N051                  # slide 틀 꺼내기 → 숫자 · 글만 바꿈
```
